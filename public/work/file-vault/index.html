The project

About File Vault

Not everyone in a business should see the payroll. File Vault gives every user an access level from 1 (Basic) to 5 (Ultimate), and every file a security level. People only ever see, search and download files at their level or below.

Higher-level files aren’t just hidden from lists, they simply don’t exist as far as a lower-level user is concerned. Administrators manage users and can see a full log of sign-ins, uploads and downloads.

How it’s built

Under the bonnet

  • PHP
  • SQLite
  • Role-based access control
  • CSRF protection
Key features

What File Vault does

Five access levels

From Basic to Ultimate. A level 3 user sees levels 1–3 and nothing above.

Upload, search, download

Drag in files, set their level, add a description and find them again quickly.

User management

Add people, change their level, disable accounts and reset passwords.

Activity log

Every sign-in, upload, download and change is recorded for peace of mind.
