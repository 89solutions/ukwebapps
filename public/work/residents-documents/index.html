The project

About Residents’ Documents

Managing agents send residents a lot of paperwork: fire safety information, building regulations, tenancy documents. Residents’ Documents gives every block a single, secure place for it.

Each resident signs in with the building code, apartment number and a password from their printable move-in letter. They see the building’s shared documents, their own apartment’s files, and can upload their own paperwork for the managing agent only.

How it’s built

Under the bonnet

  • PHP
  • SQLite or MySQL/MariaDB
  • No framework
  • Printable letters
  • Automated tests
Key features

What Residents’ Documents does

Many buildings, one install

One organisation manages any number of blocks and apartments from a single admin area.

Three levels of document

Building-wide documents for everyone, apartment documents for that flat only, and resident uploads seen only by staff.

Simple, secure sign-in

Passwords are generated at move-in, printed on a move-in letter and stored hashed. Lost ones are simply reissued.

Team logins

Staff add colleagues under Team, so everyone works from the same up-to-date records.
